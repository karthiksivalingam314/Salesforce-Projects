# Knowledge Base

Verified, durable knowledge about the TVM project. Claude adds to it as facts are confirmed.

## Status labels

Label every fact with one of these:

| Label | Meaning |
|---|---|
| **VERIFIED** | Confirmed from the Salesforce org, source, or an explicit user statement. Record the source and date. |
| **UNKNOWN** | Needed, but not yet determined. |
| **NOT PROVIDED** | Not yet supplied by the user or stakeholders. |

Never record assumptions as facts.
