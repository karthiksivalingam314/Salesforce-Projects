## Requirement

Retrieve the currently **active** versions of these Salesforce Flows from the TVM working org:

1. Assign Case Queue Based on Priority
2. Case Skill Mapping for same request types
3. Cases disposition
4. Track Agent-to-Agent Case Transfers
5. Track Internal Feedback Duration
6. Email-to-case case category auto fill

For each flow: identify the exact API name and the active version number, retrieve the active version's metadata (XML), and record the label, API name, active version, status, and other verified metadata. If a flow cannot be found or has no active version, document that instead of guessing.
